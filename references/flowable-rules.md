# Flowable Rules

Preserve Flowable-specific extensions.

Common attributes/elements include:

- `flowable:assignee`
- `flowable:candidateUsers`
- `flowable:candidateGroups`
- `flowable:delegateExpression`
- `flowable:class`
- `flowable:expression`
- `flowable:formKey`
- Flowable extension elements

The exact Flowable namespace and project-specific conventions must be taken from the existing BPMN file.

Never remove an extension simply because it is not understood.
